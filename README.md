# Sandbox Test

A simple test repository for sandbox testing and development.

## Overview

This project is designed for testing and development purposes in a sandbox environment.

## Getting Started

### Prerequisites

- Git
- Basic understanding of version control

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mihirsuchak11/sandbox-test/
```

2. Navigate to the project directory:
```bash
cd sandbox-test
```
